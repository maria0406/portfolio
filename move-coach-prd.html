PRD · Move Coach

Move Coach
PRD

The product requirements for Move Coach, the part of my rekordbox companion app that shows a beginner DJ which control to move, which way and when, on their own tracks.

Scope 8 user stories, each with testable acceptance criteria Status 4 built · 2 prototype · 2 planned Repo maria0406/RekordBox-Plugin
01 · Problem

A cue says when, not how

A cue in rekordbox tells a new DJ when to swap the bass, but not how. Beginners learn from videos that use other people's songs, so the timing never matches their own tracks.

Why it's hard today

  • When a transition sounds off, a beginner can't tell whether they moved the wrong control, turned it the wrong way or moved it too late.
  • The only feedback in the moment comes from a paid private lesson.
  • rekordbox has no public API for playback position, so any live coach has to work out where the decks are by itself.
02 · Who it's for

Student DJs on beginner controllers

Student DJs at UT who play rekordbox on a controller like the Pioneer DDJ-FLX4. The persona is Sofia, a sophomore with a new FLX4 who wants to play her org's next party. I'm user zero.

Goals

Show which control to move, which way and when, timed to the phrases of the DJ's own tracks. Use one timing engine for every view, so the animation always matches the audio. Follow a live set in rekordbox from the controller's own MIDI.

Non-goals

Scoring the audio of a mix after it's played. Copying Pioneer's hardware design or logos (the drawing is generic, with FLX4 control names). Other controllers, Windows overlay support, and full-screen rekordbox.

03 · User stories

8 stories, each with acceptance criteria

Built means it's in the app today. Prototype means the code and automated tests exist but haven't been checked end to end on the controller with rekordbox. Planned means designed, not built.

1. Watch a transition Built

As a new DJ, I want to watch each transition in my prepped set as an animated controller, so that I see which control to move, which way and when.

  • Given a prepped set, when I select a transition and press Play demo, then the controller animates each move in order: deck 2 PLAY, channel 2 fader up, bass swap, channel 1 filter, channel 1 fader down.
  • Given the next move starts within 8 bars, then the caption reads "Next: <move> in N bars".
  • Given a transition has no BASS SWAP or FILTER cue, then those moves default to 16 bars after MIX OUT and 1 bar after the swap.

2. Hear it mixed Built

As a new DJ, I want to hear the two tracks mixed while the controller animates, so that I connect each move to the sound it makes.

  • Given the demo is playing, when a move changes a control, then the browser mix applies the same fader, LOW EQ and filter value on the same frame.
  • Given the tracks have different BPMs, then the incoming track plays at the outgoing tempo with keylock on.
  • Given the audio can't load, then a silent clock still drives the animation.

3. Jump to one move Built

As a new DJ, I want to jump straight to one move, so that I can repeat the part I keep getting wrong.

  • Given a transition, when I click a move's button, then playback seeks to one bar before that move starts.
  • Given a different transition is selected, when I click a move on another one, then that transition is selected first.

4. Learn a fake drop Built

As a DJ building energy, I want to be taught a fake drop when my track has one, so that I learn a technique beyond the basic blend.

  • Given the outgoing track has a FAKE DROP cue that ends before the mix's 8-bar heads-up, then two moves are added: kill channel 1's LOW in the last half-bar, then bring it back after one bar.
  • Given the fake drop would overlap the heads-up, then it isn't taught.

5. Follow my decks live Prototype

As a DJ playing my own set in rekordbox, I want the coach to follow my decks from my FLX4, so that the prompts appear at the right moment while I play.

  • Given the FLX4 is connected, when I press LOAD, PLAY or CUE or move the tempo slider, then the estimated deck position resets, starts or stops, returns to the cue point, or changes speed.
  • Given a transition runs from deck 2 into deck 1, then the overlay swaps the deck and channel numbers in the drawing and the text.
  • Given no controller is found, then the overlay still opens and says no FLX4 MIDI input was found.

6. Re-sync after drift Prototype

As a DJ who nudged the jog wheel or used a loop, I want to re-sync the coach in one click, so that the prompts line up with my track again.

  • Given the estimate has drifted, when I press a sync button, then the outgoing deck's position is set to the track start or to 8 bars before MIX OUT.
  • Given no controller is connected, then the sync buttons still set the position, so the overlay can be driven by hand.

7. Confirm my move Planned

As a new DJ, I want the coach to confirm when I make the right move, so that I know I did it and it moves on.

  • Given a move is active, when the FLX4 reports the cued control reached its target inside the move's window, then the move is marked done and the prompt advances.
  • Given I move the wrong control, then the prompt stays.

8. See my on-time score Planned

As a new DJ, I want to see how many cued moves I completed on time, so that I can track my progress across practice sessions.

  • Given a finished practice run, then I see the share of cued moves completed on time, saved per session.
  • Given a move isn't confirmed before its window ends, then it counts as missed.
04 · Success metrics

Targets, not results yet

No testers have used Move Coach yet, so every number below is a target.

Learning metric

  • Share of cued moves completed on time, confirmed through the FLX4's MIDI. The baseline comes from each tester's first sessions, and the goal is for it to rise.

Product metrics (from the design doc)

  • Active testers: 5 DJs who prep at least one real set with the tool.
  • Would use again: 4 of 5 testers say yes in a one-question survey after a set.
  • Prep time per set: cut by at least 50% on a timed 15-track set.
  • Cue accuracy: DJs keep 70% or more of the generated cues without moving them.
05 · Risks

What could break the live coach
  • The deck estimate drifts when the DJ nudges the jog wheel, uses hot cues, loops, beat jump or SYNC. Manual re-sync covers this for now.
  • The default FLX4 MIDI map isn't verified yet. A probe script records a measured map from the real controller, and the overlay uses it when it's there.
  • Stories 7 and 8 depend on that measured map. The Phrase Countdown Light is designed to reuse the same timing engine. Its laptop-side sender isn't built yet.
